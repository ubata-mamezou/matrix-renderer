# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately using
[GitHub's private vulnerability reporting](https://github.com/ubata-mamezou/matrix-renderer/security/advisories/new).
Do not disclose vulnerability details in public issues or discussions.

Include the affected version, steps to reproduce, potential impact, and any
known workaround. Please do not include real user data, credentials, or other
secrets in a report.

If private reporting is unavailable, open a public issue asking for a private
reporting channel. Do not include vulnerability details in that issue.

## Response and Disclosure

We aim to acknowledge reports within 7 days and coordinate a disclosure
timeline with the reporter. When feasible, we aim to release a fix and
coordinate public disclosure within 90 days after confirming a vulnerability.
These are targets, not guaranteed deadlines; active exploitation or other
urgent circumstances may require a different timeline.

## Supported Versions

Security fixes are generally made for the latest released version. Please
upgrade to the latest version when reporting an issue.
