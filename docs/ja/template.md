# YAML設定テンプレート

マトリクスの設定ファイル仕様は以下の通りです。

```yaml
title: テンプレートです # マトリクスタイトル　※任意
width: 800 # マトリクスの幅　※任意（デフォルト1400）
lineColor: "#8798a8" # マトリクスの罫線色　※任意（既定値: #d7e0e8）
xAxis: # X軸方向のラベル指定（=列）
  label: X軸の説明 # x軸のラベル
  values: # X軸の設定
    - label: 列１ # X軸のラベル
      color: "#d6eaf8" # 列の色（RGBまたはRRGGBB形式）　※任意
    - 列２ # X軸のラベル（色指定なし）
    - label: 列３ # X軸のラベル（色指定なし、属性名あり）
    - label: 列４
      color: "#d6ea00"
      sub-labels: # 段組み指定
        - 列４１
        label: 列４２
        sub-labels:
          - 列４２１
          - 列４２２
yAxis: # Y軸方向のラベル設定（=行）
  label: Y軸の説明 # Y軸のラベル
  values: # Y軸の設定
    - label: 行１ # Y軸のラベル
      color: "#c5e4ec" # 行の色（RGBまたはRRGGBB形式）　※任意
    - 行２ # Y軸のラベル（色指定なし）
    - label: 行３ # Y軸のラベル（色指定なし、属性名あり）
    - label: 行４
      color: "#d6ea00"
      sub-labels: # 段組み指定
        - 行４１
        label: 行４２
        sub-labels:
          - 行４２１
          - 行４２２
items: # プロットするアイテムの設定
  - id: item1 # アイテムのID
    label: アイテム１ # アイテムのラベル
    lane: 行１ # アイテムを配置する行（Y軸のラベルを指定）
    from: 列１ # アイテムを配置する開始列（X軸のラベルを指定）
    to: 列１ # アイテムを配置する終了列（X軸のラベルを指定）
    url: https://example.com/guide # アイテムのリンク　※任意
    color: "#245080" # アイテムの色（RGBまたはRRGGBB形式）　※任意
  - id: item2
    label: アイテム２
    lane: 行１
    from: 列２
    to: 列２
    before-item: item1 # item1の右側に配置　※任意
```

## 属性仕様

|項目|必須|制約|デフォルト値|説明|
|---|---|---|---|---|
|`title`|いいえ|－|`no title`|マトリクスのタイトル|
|`width`|いいえ|1400|700～4000|出力画像の幅|
|`lineColor`|いいえ|`#RGB`or`#RRGGBB`形式|`#d7e0e8`|罫線と軸見出し境界の色|
|`xAxis.label`|はい|－|－|X軸の見出し。X軸はマトリクスの列です。|
|`xAxis.values`|はい|空配列はNG|－|列の定義。YAMLに記述した順序で左から描画します。|
|`xAxis.values[n].label`|はい|X軸内で一意であること|－|列のラベル|
|`xAxis.values[n].color`|いいえ|`#RGB`or`#RRGGBB`形式|－|列の色|
|`xAxis.values[n].sub-labels`|いいえ|ルート含めて最大3階層まで|－|列の段組み指定。空配列の場合は無指定として扱います。|
|`yAxis.label`|はい|Y軸内で一意であること|－|Y軸の見出し。Y軸はマトリクスの行です。|
|`yAxis.values`|はい|空配列はNG|－|行の定義。YAMLに記述した順序で上から描画します。|
|`yAxis.values[n].label`|はい|Y軸内で一意であること|－|行のラベル|
|`yAxis.values[n].color`|いいえ|`#RGB`or`#RRGGBB`形式|－|行の色|
|`yAxis.values[n].sub-labels`|いいえ|ルート含めて最大3階層まで|－|行の段組み指定。空配列の場合は無指定として扱います。|
|`items`|はい|空配列はNG|－|配置するアイテムの配列|
|`items[n].id`|はい|アイテム内で一意であること|－|アイテムを識別する一意なID。|
|`items[n].label`|はい|－|－|帯に表示するラベル。長いラベルは複数行に折り返します。|
|`items[n].lane`|はい|Y軸ラベルに存在するリーフラベルであること。|－|配置するY軸の行ラベル。|
|`items[n].from`|はい|X軸ラベルに存在するリーフラベルであること。|－|配置範囲の開始X軸ラベル|
|`items[n].to`|はい|X軸ラベルに存在するリーフラベルであること。fromより右にあたるラベルのみ指定可（同値可）。|－|配置範囲の終了X軸ラベル|
|`items[n].url`|いいえ|HTTPまたはHTTPSのURL|－|クリックすると新しいタブで開くリンク先になります　※SVGのみ|
|`items[n].color`|いいえ|`#RGB`or`#RRGGBB`形式||アイテム帯の塗り色|
|`items[n].before-item`|いいえ|このアイテムより左に置くアイテムのID|－|アイテムの前後設定|

* X軸
  * 描画順: xAxis.valuesに定義された順に描画します
  * 横幅
    * 各列は等幅です。
    * 上位にあたるラベルは、下位にあたる列の幅を結合して表示します。
* Y軸
  * 描画順: yAxis.valuesに定義された順に描画します
  * 縦幅
    * ラベルごとに、その行のアイテム数とラベルの折り返しに応じた高さを割り当てます。
    * 上位にあたるラベルは、下位にあたる行の高さの合計を結合して表示します。
* 罫線色（`lineColor`）
  * 罫線と軸見出し境界に適用します。
  * アイテム帯の枠線は各アイテムの色から決めるため、対象外です。
* X軸、Y軸の色（`xAxis.values[n].color`, `yAxis.values[n].color`）
  * 自身に指定があればその色を使用します。
  * 指定がなければもっとも近い上部の色を継承します。
* 段組み（`xAxis.values[n].sub-labels`, `yAxis.values[n].sub-labels`）
  * sub-labels配下はルート同様、`label`,`color`,`sub-labels`を指定可能。
* 項目の前後関係（`items[n].before-item`）
  * 前後関係に指定可能な値
    * 存在しないアイテムは指定不可。
    * 異なるY軸のアイテムIDは指定不可。
    * X軸の範囲が重なるアイテムは指定不可。
    * 参照先は指定元より左に配置されていなければなりません。
    * 複数のアイテムから同じアイテムを参照することはできません。（NG例: item2がitem1、item3もitem1を指定）
    * 前後関係は連鎖可能。（例: item2がitem1、item3がitem2を指定するのはOK）
* アイテムの配置
  * 前後設定されたアイテムは同じトラックに配置されます。
  * 前後関係のないアイテムは空き領域へ自動配置されます。
